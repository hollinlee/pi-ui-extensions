# pi-ui-extensions

> Enhanced UI extensions for Pi coding agent - customized version based on pi-cc-extensions

**Status**: 🚧 Initial setup - forked from [pi-cc-extensions](https://github.com/minuque/pi-cc-extensions)

## Features (from pi-cc-extensions)

- **Claude Code UI**: Tool summary, fold/expand, rich edit/write diff with `on` / `compact` / `off` modes
- **Markdown enhancements**: Mermaid diagrams, callouts, URL linking
- **Fullscreen mode**: Click to expand/collapse tool cards, preview, hover highlight
- **Configuration panel**: Style / Features / UI / Diff / Thinking / Footer tabs via `/ccstyle`
- **Context checker**: View context usage via `/context`
- **Session/Subagent reference**: Search and inject history via `@`
- **Status bar**: Model, context, cache, cost, git info
- **Themes**: CC Dark, CC Light

## Installation

```bash
pi install git:github.com/hollinlee/pi-ui-extensions
```
